Overstory is a 3D platformer project focused on movement-based gameplay, environmental challenges, and responsive player interaction.
--------------------------------------------------------------------------------------------------------------------------------------------------------------------
The project explores mechanics including:

Double jump and air dash movement
Projectile-based combat
Collectibles and progression
Physics-based moving platforms
Rotating and flipping platforms
Interactive NPCs
Controller and keyboard support
Tutorial-driven ability progression
Cross-level progression
Gameplay audio
Scene and game-state management

--------------------------------------------------------------------------------------------------------------------------------------------------------------------
Technical Focus:

The game is built in Unity using C# and uses Unity's Rigidbody physics and Input System to create responsive player movement and interactive environmental objects.

A major focus of the project has been designing platforming challenges that require the player to combine movement abilities with environmental timing.

--------------------------------------------------------------------------------------------------------------------------------------------------------------------
My Contributions:

I designed and implemented the gameplay systems, player mechanics, environmental interactions, progression systems, audio integration, and level scripting.

The project also served as an opportunity to practice debugging real gameplay problems involving physics, collision detection, scene management, input handling, and persistent game state.
